# 🐻 A Bear's Journey

An interactive, poetic storytelling website following a lonely bear's quest to reunite with his partner.

## ✨ Features

- 🎭 **Cinematic Storytelling:** Smooth animations and atmospheric transitions.
- 📱 **Mobile-Optimized Vertical Layout:** Perfectly fitted viewport (`100dvh`) with zero vertical scrolling on mobile devices.
- 📜 **The Chronicles (Embedded Document Viewer):** Sequential document viewer with intuitive arrow navigation.
- 🌿 **Branch Password Challenge:** Interactive checkpoint leading into the grand show.
- 🎪 **Stage Curtain Reveal:** Velveteen stage curtain opening accompanied by soft ambient piano BGM.
- 📖 **Story Chapters:** Free chapter navigation with touch buttons and keyboard arrow support.
- ⏱️ **Countdown Timer:** Anticipation build-up with a responsive progress timer.
- 💕 **Reunion Celebration:** Floating heart animations celebrating the reunited bears.
- ✍️ **Typewriter Letter:** Moving typewriter poetry with piano soundtrack.
- 🔄 **Replay & Skip:** Seamless replay system with skip capabilities.
